We spend weeks on development - RAP, UI5, Fiori, CDS... Then the user says: "This is not what we expected." And we have to go back and make changes.

Most projects don't have a dedicated UI/UX designer. But as SAP consultants, we should also understand how the requirement can be achieved, what is possible, and what is not possible before we start building it.

Even a simple Figma prototype can help. SAP also provides the **SAP S/4HANA Web UI Kit for Figma**. Use it to create a simple prototype, show the user what you're planning to build, and get their feedback before starting development. Make changes early. Then start coding.

A little time spent upfront can save a lot of development effort later.
